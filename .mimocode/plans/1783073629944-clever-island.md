# LampShade UI Replacement Plan — React + TypeScript + Ant Design

## Architecture Overview

```
LampShade/
├── LampShade.Api/          # Backend REST API (port 5002) — API-only, no UI
├── FrontEnd/               # React + TypeScript + Vite + Ant Design (port 5173)
├── ServiceHost/            # Legacy Razor Pages — TO BE REMOVED after React is working
├── 0_Framework/            # Shared utilities
├── 01_LampShadeQuery/      # Query models / CQRS
├── AccountManagement/      # DDD module
├── BlogManagement/         # DDD module
├── CommentManagement/      # DDD module
├── DiscountManagement/     # DDD module
├── InventoryManagement/    # DDD module
├── ShopManagement/         # DDD module
└── LampShade.sln
```

## Pages

1. **Home** — Carousel (slides), product categories, latest products, features, latest articles
2. **Product Category** — Breadcrumb, product grid, sort/filter, pagination
3. **Product Detail** — Image gallery, product info, add to cart, description tabs, comments
4. **Search** — Search input, results grid, empty state
5. **Cart** — Table with items, quantity editing, totals, checkout button
6. **Checkout** — Order summary, payment method selection, address, pay
7. **Login** — Username/password form
8. **Register** — Registration form
9. **Account Profile** — User info, edit
10. **Account Orders** — Order history table
11. **Payment Result** — Success/failure page

## Assumptions

1. Backend API on port 5002 is running and accessible
2. CORS is already configured (AllowAll policy)
3. Product images served from `/ProductPictures/` as static files
4. Auth is cookie-based, not JWT
5. All UI text is in Persian (Farsi) with RTL layout
6. Slugs are used for product/category/article URL routing
7. Payment methods are hardcoded (online + cash on delivery)
